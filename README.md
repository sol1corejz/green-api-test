# MAX Chat (React + GREEN-API)

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте в браузере адрес из терминала (обычно `http://localhost:5173`).

Для входа нужны `idInstance` и `apiTokenInstance` из [личного кабинета GREEN-API](https://console.green-api.com/).

## Сборка

```bash
npm run build
npm run preview
```
